What is built in the sgit app

The reality file for the sgit app. If it is not listed here as built, it does not exist. The design is intention; this page is fact, and it changes in the same commit as the code it describes.

Status words: built is in the repository and proven by a test that ran; unverified is written but has not been proven by a run (of CI, on a device, or against a server, as the row says); proposed does not exist.

Built

Nothing is marked built yet: the code below has been written on the branch work/sgit-app and has not yet been compiled. CI is the compiler; this page changes when it has run.

WhatWhereWhat would prove it
Files over 4 MB in the vault engine unverifiedPackages/SGitVault: VaultStreamCipher.swift (AES-256-GCM as a stream, so a file is sealed and opened from disk to disk), VaultLargeTransport.swift (sgit's upload in parts and download in ranges), VaultLargeFiles.swift (staging, a commit of staged files, download with every check)LargeFileTests on the CI Mac; sgit-app.yml has sgit clone what Swift wrote and Swift read what sgit wrote. The exchange with the live server has only been run with sgit itself, not with the Swift code
The app unverifiedApps/SGit/: its own project, bundle ai.sgit.app, iPhone and iPad, iOS 26, SwiftUI, Apple SDK onlysgit-app.yml: a simulator build, a Release build, unit tests on an iPhone and an iPad simulator
Vaults on the device unverifiedEngine/VaultShelf.swift, UI/VaultsView.swift: add by key, read key or web link, pasted or scanned as a QR code; create; keys, access token and signing key in this app's KeychainUnit tests against a vault in a folder. Never run on a device
Adding photos, videos and files unverifiedEngine/Outbox.swift, Engine/Intake.swift, UI/VaultView.swift: a selection is copied in, encrypted to disk, uploaded and committed as one signed commit; progress for each file and the whole; a failed job is kept and can be tried again or discarded; a job survives the app closing; a refused push is tried again on the new headUnit tests: a selection read back byte for byte, a failed upload carried on by a new Outbox, discard, a read key refused. The pickers and the live server: never run
Browsing unverifiedUI/VaultView.swift, UI/FileView.swift: folders, a grid or a list, thumbnails for images, an image at full size, a video player, Quick Look, Save to Photos, Share, rename, deleteThe listing, rename and delete have unit tests. The screens have never been seen
Sharing a vault unverifiedUI/ShareVaultView.swift: the vault key and the read key as text and QR code, with what each gives; a link for the web Vault UIThe link's form has a unit test. Whether the web Vault UI opens a vault this app wrote has not been tried
History unverifiedUI/HistoryView.swift: commits, signature, the signing key's fingerprint, whether it is this device's, what changedUnit tests for the changes and the fingerprint
