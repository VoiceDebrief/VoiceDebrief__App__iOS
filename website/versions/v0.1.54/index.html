What changed in v0.1.54

Released 14 November 2026. Every push to the repository's dev branch is a release; this page was written by CI from the notes that came with it. Every version · What is built

A new shared package, SGitPeople, the layer under both apps for people, messages and secrets (issue 200). The key bundle (PKIKit) and the lane envelope move into it from VoiceDebrief, unchanged. New in it, not yet on any screen: a signed contact card that fits a QR code, contacts with how each was met, sealed and signed messages, an inbox client tested against answers recorded from the live server, when to check for new messages, a secrets store that remembers who holds each secret, and the first exchange that gives a newcomer the access key.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
