# What changed in v0.1.139

Released 16 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

Set up as a cell (`cells/crm-ios/`: objective, deliverable, behaviour policy, brief) with its own builder session; issue 400. App Store name SGit CRM, bundle id `ai.sgit.crm.app`. No app code yet.
