# What changed in v0.1.145

Released 17 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

Any common audio or video file can now become a note: WhatsApp voice notes (.opus, .ogg), MP3, M4A, WAV, FLAC, AIFF and the sound of MP4, MOV and 3GP videos, chosen in the app. The format is worked out from the file itself, so a mislabelled file still works; WhatsApp's are decoded on the device with Apple's own Opus decoder. Ogg Vorbis and WebM say plainly they are not supported yet, and a damaged file says so and is kept. Not yet tried on a device; receiving files from the share sheet comes next.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
