# What changed in v0.1.131

Released 16 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

Each recorded note now carries a short microphone check, sent with it: the recorder's loudest reading, the live engine's loudest sample, which microphone it used, and whether the note was rescued from the live audio. A fifth silent note came in on 0.1.126; this says which part went deaf.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
