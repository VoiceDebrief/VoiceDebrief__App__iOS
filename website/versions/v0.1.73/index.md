# What changed in v0.1.73

Released 14 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

The Lab's control centre (L02) now carries out two confirmed actions, the two that are safe to undo: opening a section of the app, and finding a note, which only reads the library and lists what it found on the card. Nothing happens before Do it, unless that action is switched to go ahead without asking. The other five actions are still recorded only, and each card says which it was. In test: no sentence has been put to a model.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
