# What changed in v0.1.78

Released 14 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

The Lab's control centre (L02) gains a third action it can carry out: record a note for a named person. It always waits for Do it and cannot be switched to go ahead by itself, because a note recorded for a person is sent to them when it is finished; the card says so before the button is pressed, and afterwards shows what the app answered, including a refusal when no contact has that name. The Lab's side only: until the Record screen is connected to it, the card says recording is not connected. A correction made afterwards in the log no longer carries anything out.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
