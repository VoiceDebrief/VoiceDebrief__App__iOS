# What changed in v0.1.132

Released 16 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

SGit Secrets, first building block: a vault can now be written as one file and read back safely (anything that could escape the vault's folders is refused), two copies that changed apart can be joined, and a file is replaced in one step with five earlier copies kept. It is the store the secrets app will keep in iCloud Drive; nothing on screen yet.

The secrets app has a name and decisions: SGit Secrets; pay as you go with credit, a £5 starter switching on a server copy; vaults shared between people only through the server, with keys exchanged between them, never a shared iCloud folder. The plan now starts with the one-file store, and sharing comes with the server in a second version. [Read it](../../articles/secrets-app/index.md).

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
