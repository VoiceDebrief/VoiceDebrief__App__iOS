# What changed in v0.1.81

Released 14 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

Faces in more places: each contact in Contacts shows its avatar, an agent's conversation opens with you, an arrow and the agent, and the card that follows a send shows the same route above its steps. A contact is drawn the same way everywhere (Claude, the built-in recipient, as a conductor).

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
