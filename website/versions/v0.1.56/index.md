# What changed in v0.1.56

Released 14 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

From the owner's notes while driving: "send this now" no longer fires on "don't send it now", and waits for a pause, so saying it in passing does not stop the recording; the words that act are shown under the control while recording. The level bars stay pinned with the control and are less sensitive, so speech no longer looks maxed out. The On this device and Network panel becomes two small icons in the bar, steady, green while in use; tap them for what each means and a log of what happened.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
