# What changed in v0.1.52

Released 14 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

External testers get builds regularly: a new workflow puts a dev build of either app in front of its public TestFlight link when the commit says [external], when the version ends in 0, or by hand; it waits for processing, writes What to Test from that version's page, adds the build to the external group and submits it for Beta App Review.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
