# What changed in v0.1.60

Released 14 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

SGitPeople's messages are now pki.sgit.ai's own (its message form, signed inside and out, handed over as its m1 code), so pki.sgit.ai's pages and agent tool read what the apps send; checked against pki.sgit.ai's code in a new workflow. A reply names the note it answers, for the talk-to-the-developer button. An invitation expires after seven days, and a newcomer may show pki.sgit.ai's k1 key code instead of a card.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
