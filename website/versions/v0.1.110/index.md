# What changed in v0.1.110

Released 14 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

On iPhone, a part of the app reached through More no longer shows two back buttons: the tab bar is Record, Library, Contacts, Vaults and More, and More is now the app's own list of the other parts, grouped as the sidebar groups them, each opening with its own single navigation bar. The Guide leaves room at the bottom for the Talk button.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
