# What changed in v0.1.127

Released 15 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

Silent recordings: two of the owner's notes tonight (16 s and 63 s, 0.1.123) and earlier ones were pure digital silence, the recorder writing zeros while the live words' audio engine held the microphone. Now the live engine's own audio is kept beside the note while it records, and if the recorder's file turns out silent while the engine heard sound, the note is made from the engine's audio instead, so the words are not lost. While that happens the screen says the recording is being kept from the live audio, and the live words keep running. A flaky test fixed (a server's id could contain the test token).

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
