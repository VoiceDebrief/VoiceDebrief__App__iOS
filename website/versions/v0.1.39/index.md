# What changed in v0.1.39

Released 14 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

The sgit app gains a gallery: a list of vaults to show somebody, by topic, each opened in the web Vault in a browser inside the app. The list is data, added on the device or read from a `showcase.json` in a vault; it ships empty. Also a picture of every screen of the sgit app from CI, and fixes those pictures called for.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
