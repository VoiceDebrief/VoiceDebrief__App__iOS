# What changed in v0.1.137

Released 16 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

From the owner's memos on 0.1.133. Live: Full details on a memo opens it all at once, your words, the picture that went with it, Claude's answers with their pictures, a small diagram of the sequence of events with each step's time, and the timeline. The picture sent with a note is now kept with it. Agents: sub-tabs by topic, with Waiting for input first, gathering every waiting agent from every project; live counts replace the old drawing; tap an agent for its details and a box to write to it, which goes to Claude to pass on. The right-hand side shows an Update button when a newer build is in TestFlight. Messages to Claude opens large on an iPad, your memos and their answers first and Claude's other messages below, with pictures.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
