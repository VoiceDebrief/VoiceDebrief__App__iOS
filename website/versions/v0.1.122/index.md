# What changed in v0.1.122

Released 15 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

The sgit app opens a vault in its own app when it has one, full screen, with an App and Files switch; shows a vault of photos as a gallery you swipe through, and can add a gallery page to it so it opens as a gallery on the web too; moves several files or folders to another folder in one change; marks each file as on this device or still on the server; opens a photo or video full screen when tapped, with (i) for its details; gives a way up from a folder on an iPad or a Mac; and shows a vault under its own name

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
