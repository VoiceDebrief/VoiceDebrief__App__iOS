# What changed in v0.1.30

Released 14 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

Finish and send in one press: while recording, a button for each of your own recipients finishes the note, sends it as soon as it is written up, and leaves you on the record screen for the next one (issue 026). Sends now go one after another, so several notes sent in quick succession all go. A note remembers who it was sent to and when, on the note and in the list.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
