# What changed in v0.1.77

Released 14 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

Three notes from 0.1.72 arrived as pure silence (-91 dB throughout): nothing reached the microphone. While recording, the app now says so after three seconds of true silence ("No sound is reaching the microphone: another app may be using it"), so a silent recording is noticed at once. A quiet room does not trigger it.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
