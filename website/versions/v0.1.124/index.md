# What changed in v0.1.124

Released 15 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

Live with Claude, on the right of the record screen on an iPad or a Mac, for the owner's demo: each memo sent to Claude is a card with its status (sending, sent, Claude has it, answered), a clock running from the send until the answer, Claude's answer under it with a picture when one comes, and a timeline you can open showing each step and how long it took (recorded, written up, sent, reached Claude, answered, shown here), drawn as bars on one time line. While the panel is on screen it checks the agents vault every ten seconds and says when it last looked. Clear hides the memos so far.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
