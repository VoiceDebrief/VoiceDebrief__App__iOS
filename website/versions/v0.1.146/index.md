# What changed in v0.1.146

Released 17 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

Forward a WhatsApp voice note, an audio file or a video to VoiceDebrief: in WhatsApp (or Files, Photos, or any app) choose Share, then VoiceDebrief, and "Debrief in VoiceDebrief". The note waits safely until VoiceDebrief is opened, then appears in the library and is transcribed, debriefed and saved like a recording. The owner registered the identifiers it needs on 17 November; if signing still fails, the build goes to TestFlight without it, as before, and says so. Not yet tried on a device.

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
