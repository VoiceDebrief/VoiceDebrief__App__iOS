# What changed in v0.1.107

Released 14 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

The sgit app's Gallery shows the vaults published at sgit.ai/demos/vaults, 54 of them, grouped by kind and searchable; each opens live in the web Vault inside the app, to look at, with the read key its maker published. The list is read from sgit.ai each time, so new vaults appear without an update

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
