# What changed in v0.1.58

Released 14 November 2026. Every push to the repository's `dev` branch is a release; this page was written by CI from the notes that came with it. [Every version](../index.md) · [What is built](../../built/index.md)

The sgit app keeps a record of what you do in it (Settings, Your activity): every screen and how long it was open, and every action, with no file names, vault names or keys. A button sends it, encrypted, to the developer. Each device keeps its own. The whole web Vault opens inside the app on the vault or the file you are looking at (three dots, Open in the web Vault): folders, HTML preview, Markdown, editing. It opens looking only; Allow changes lets it save. Also new on the site: a guide to the app in pictures, with the things to press numbered

Pictures of the screens are added to this page when the screens workflow has taken them for this version.
