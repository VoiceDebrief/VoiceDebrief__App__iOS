Known limits of what is built

  • Live vault writes are unproven. The vault engine's writes have been tested against sgit's in-memory server and read back by sgit, never against the live server, which needs an access token. This was true in the repository it came from and is still true here.
  • Nothing has run on a device. CI builds for the simulator and for a device, and tests on simulators. No build has been installed on an iPhone or iPad.
  • The four spikes in the plan have not been run: passkey bytes in a native app, the quality of Apple's models on real voice notes, live vault writes, and Ogg Opus decoding. Each can change the plan.
