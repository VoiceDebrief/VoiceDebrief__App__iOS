# 021: Analyse while recording: a semantic graph, a title, pictures

**Status:** open. Asked for by the owner, 13 November 2026. Laboratory work first (see 012).

The model is on the device and costs nothing to ask, so there is no reason to wait for Stop.

1. **A graph as you speak.** At intervals, ask the model for what the words so far contain: facts, ideas,
   flows, names, entities, and how they connect. Draw it as it grows, so the speaker can connect the dots or
   correct it. Two levels of detail; more room on an iPad.
2. **Two graphs compared.** The same note through the on-device model and through Private Cloud Compute (015).
3. **The screen reflects what is known.** The title, the main areas and the note's page come from the graph.
4. **Pictures.** Past a certain size, a separate model session writes an image prompt and an image is made
   from it. Note: Apple's image generation is a system sheet (Image Playground), not a call the app can make
   silently, so find out what is possible first.
5. **Can the model write SVG or HTML?** An icon for a note; a variation of the debrief as a small page the app
   renders. Try it and record what comes back.

Follows [Two decision engines](../../website/articles/two-decision-engines/index.md): one question at a time,
through function calls, the code owning the state.
