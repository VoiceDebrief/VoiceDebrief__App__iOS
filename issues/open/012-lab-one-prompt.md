# 012: The lab, first experiment (L01): one prompt, tools on and off

**Status:** open. See the articles "The lab" and "Two decision engines".

A Lab section: one prompt to the on-device model with a chosen set of tools, and everything shown: what the
model was given, each tool call, the answer, the time. This is also the first slice of the model "door"
(issue 013). Find out how reliably the on-device model calls tools before building anything on it.

## Where it stands (13 November 2026)

Built and in the test build: the Lab under Settings, L01, four read-only tools, six presets, the export.
Compiled and unit tested in CI; never run against a model. Open until the owner runs the presets on an iPhone,
an iPad and a Mac and sends back the exported runs. What the runs show decides L02.
